# Firstgame

Зимние гонки на тюбинге в Roblox.

## Общий Codex-плагин Roblox Standards

В `plugins/roblox-standards` находится независимый от игры плагин общих
паттернов Roblox. В нём шесть skills: инициализация общих файлов,
настройка проекта, интерфейсы, окружение, эффекты и тестирование. Документация и шаблоны устанавливаются
вместе с пакетом. Каталог: `.agents/plugins/marketplace.json`.

[Установка, использование и публикация плагина](plugins/roblox-standards/README.md).

После загрузки этих файлов на GitHub участники смогут подключить пакет:

```sh
codex plugin marketplace add bobkovIBAS/Firstgame --ref main --sparse .agents/plugins --sparse plugins/roblox-standards
codex plugin add roblox-standards@roblox-dev-kit
```

Для локальной проверки из этой папки используйте `codex plugin marketplace add .`.

## Открыть проект

В Roblox Studio выберите **File → Open from File** и откройте `Firstgame.rbxl`.
В лобби доступны два мира, «Зимняя ферма» и «Замёрзший порт», по пять трасс в каждом. Выберите мир у ворот или через кнопку «Тематики».

## Управление

- Enter — начать заезд.
- A / D — перемещаться по окружности тюбинга. Тюбинг разгоняется в противоположную сторону от персонажа.
- Пробел — разгон. Полного заряда хватает на четыре секунды.
- S — остановка. R — новый заезд.

## Работа через Git

```sh
git clone https://github.com/bobkovIBAS/Firstgame.git
cd Firstgame
git pull --ff-only
```

`Firstgame.rbxl` — бинарный файл. Git хранит его версии, но не объединяет параллельные изменения карты или скриптов внутри него автоматически.
Пока работайте над полным файлом по очереди: договоритесь, кто его меняет, перед работой выполните `git pull`, после работы сохраните локальную копию из Studio, затем сделайте commit и push.
При конфликте не перезаписывайте чужую карту: перенесите нужные изменения вручную в Studio.

```sh
git add Firstgame.rbxl
git commit -m "Describe game changes"
git push origin main
```

Для одновременной разработки скриптов следующим шагом стоит настроить Rojo: хранить Luau-код отдельными файлами, а карту согласовывать отдельно. В этой версии синхронизация Rojo не настроена.
