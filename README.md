# Firstgame

Игра Roblox: гонка на пончике по водной трассе.

## Открыть проект

В Roblox Studio выберите **File → Open from File** и откройте `Firstgame.rbxl`.
Это полная копия проекта: карта, два уровня, модели, интерфейс и скрипты.
Внешние меши и текстуры Roblox загружаются по идентификаторам ассетов и могут требовать доступа к Roblox.

В проекте: два уровня по четыре участка длиной 250 studs, зеркальные повороты, выбор уровней, старт по Enter с отсчётом 3–2–1, таймер и финиш.

## Управление

- A / D — перемещение персонажа по окружности пончика.
- Пончик движется в противоположную сторону от позиции персонажа.
- Удержание пробела — движение. После отпускания пончик плавно тормозит примерно 0,8 секунды с полной скорости, сохраняя прежнее направление.
- A / D без пробела меняют положение персонажа и направление следующего движения, но не разгоняют пончик.
- S — остановка; R — новый заезд.
- Enter — запуск отсчёта перед заездом.

## Работа через Git

```sh
git clone https://github.com/bobkovIBAS/Firstgame.git
cd Firstgame
git pull --ff-only
```

`Firstgame.rbxl` — бинарный файл. Git хранит его версии, но не объединяет параллельные изменения карты или скриптов внутри него автоматически.
Пока работайте над полным файлом по очереди: договоритесь, кто его меняет, перед работой выполните `git pull`, после работы сохраните локальную копию из Studio, затем сделайте commit и push.
При конфликте не перезаписывайте чужую карту: перенесите нужные изменения вручную в Studio.

```sh
git add Firstgame.rbxl
git commit -m "Describe game changes"
git push origin main
```

Для одновременной разработки скриптов следующим шагом стоит настроить Rojo: хранить Luau-код отдельными файлами, а карту согласовывать отдельно. В этой версии синхронизация Rojo не настроена.

## Текущая копия

Актуальная версия проекта Studio `PuppyGame` от 5 ноября 2026 года. Уровни разделены в `Workspace → CushionLevels → Level1 / Level2`; общая механика находится в `ServerScriptService → CushionServer`, управление и инструкция — в `StarterPlayer → StarterPlayerScripts → CushionClient`.

На первом уровне расширена земля вокруг трассы, добавлены три вида травы и шипы вдоль бортиков. Касание шипов сбрасывает заезд и таймер: для нового старта нужно снова нажать Enter. Оба уровня используют движение только при удержании пробела с коротким движением по инерции после отпускания.

Копия включает объекты резервных копий в ServerStorage, созданные во время разработки. Новый игровой тест перед загрузкой в GitHub не запускался.
