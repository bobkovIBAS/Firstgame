# Firstgame: игра и общий Roblox-плагин

Репозиторий содержит существующую игру `Firstgame.rbxl` и независимый пакет
`plugins/roblox-standards`. В задачах плагина работай с пакетом и каталогом
`.agents/plugins/marketplace.json`; изменения игры относятся к отдельным задачам.

Плагин предназначен для разных игр. Общие правила находятся в его `docs/`,
skills ссылаются на них относительными путями внутри пакета. Палитра,
координаты, названия объектов и режим синхронизации конкретной игры задаются
в профиле проекта-потребителя. Не переноси их в общие стандарты.

При изменении skills сохрани точные области применения в `description`.
Проверь локальные ссылки и пути, используемые после установки в кэш плагинов.
При изменении пакета выполни:

```sh
python3 plugins/roblox-standards/scripts/validate_plugin.py
python3 -B -m unittest discover -s plugins/roblox-standards/tests -v
git diff --check
```

Команды публикации и установки описаны в
[README плагина](plugins/roblox-standards/README.md).
Не утверждай, что локальные изменения уже загружены на GitHub или установлены
в сессии других участников. Текущую историю и изменения соавторов сохраняй.
