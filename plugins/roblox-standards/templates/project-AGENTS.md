# Фрагмент инструкций для игрового проекта

При настройке добавь содержимое ниже в AGENTS.md проекта, объединив его
с существующими правилами. Используй фактический путь профиля оформления,
если он отличается от предложенного. Не заменяй файл целиком.

```markdown
## Roblox: общие стандарты и стиль проекта

Используй установленный плагин Roblox Standards для подходящих задач:

- roblox-init — проверить и создать недостающие общие файлы.
- roblox-ui — интерфейсы и состояния.
- roblox-world — окружение, модели и интерактивные точки.
- roblox-vfx — частицы, следы и предпросмотр.
- roblox-testing — проверка затронутого поведения.
- roblox-setup — настройка документации и маршрутизации.

Профиль оформления проекта: docs/design/README.md.
Карточки повторяемых элементов: docs/design/components/.
Конкретные визуальные значения и темы берутся из профиля этой игры.
Пакет общих стандартов содержит процедуры и общие паттерны.

Перед изменением прочитай актуальные файлы или Source в Studio в
согласованном процессе синхронизации. Сохраняй изменения соавторов.
При изменении принятого паттерна обновляй его описание.
В отчёте различай реализацию, наблюдаемую проверку и публикацию.
```
