# Проверка Roblox-механик

Выбери проверки по риску и ожидаемому поведению. Простая визуальная правка
не требует полного набора сетевых или сохранённых сценариев; изменение
покупки или общего состояния требует соответствующих проверок.

| Изменение | Полезное наблюдение |
| --- | --- |
| Скрипт | Анализ/компиляция и выполнение затронутого сценария |
| UI | Реальный ввод, состояния, закрытие и целевые размеры экрана |
| Постройка | Проход персонажем, коллизии и видимость с игрового ракурса |
| VFX | Запуск, остановка, сброс, читаемость в движении |
| Сеть | Что видят сервер и минимум два клиента, допустимые и отклонённые запросы |
| Сохранение | Повторный вход, повторная выдача, ошибка и конкурирующее обновление |

## Режим и постоянные изменения

Сначала установи активные Studio, place и режим. Постоянную правку внеси
в согласованный источник, затем запусти свежий тест. В Test и Test Here
есть клиентская и серверная симуляции. Run не добавляет обычного игрока,
поэтому не заменяет проверку интерфейса и управления персонажем.
Для взаимодействия нескольких игроков используй Server & Clients или
согласованный Team Test.

## Границы наблюдения

Чтение свойства не доказывает визуальное качество. Успешный прямой вызов
функции не доказывает, что кнопка подключена к ней правильно. Локальная
проверка интерфейса не доказывает, что сервер подтвердил действие.
Используй подходящий уровень наблюдения для каждого вывода.

Проверь Output и отделяй ошибки игры от сообщений инструментов.
Если проверка остановилась с ошибкой, разберись с её причиной перед
зависимыми шагами. Не продолжай цепочку так, будто исходная проверка прошла.

При отсутствии подключённой Studio можно анализировать файлы и подготовить
план проверки. Укажи, что живое поведение осталось непроверенным.
Для профилирования сравнивай одинаковые сцену, ракурс, устройство и графику;
не делай вывод о производительности всей игры по одному короткому запуску.

## Отчёт

Запиши ожидаемый результат, выполненный сценарий, наблюдаемый результат
и существенные ограничения. Различай локальную проверку, проверку с другими
игроками и проверку опубликованной игры. Повторяй или расширяй проверки,
когда изменение, ошибка или остающийся вопрос это оправдывают.

Первичные источники: [режимы Studio](https://create.roblox.com/docs/studio/testing-modes),
[отладка](https://create.roblox.com/docs/studio/debugging).
