# Подключение стандартов к проекту

Прочитай [индекс пакета](../../docs/README.md) и
[источник исходников](../../docs/source-of-truth.md).
Ссылки здесь относятся к папке установленного skill; проект пользователя
может находиться в другом каталоге.

Найди корень целевого проекта, его AGENTS.md, README, профиль оформления
и конфигурацию синхронизации. Для живой Studio определи выбранный place
и доступный режим. Отдели подтверждённые сведения от предположений.

При запросе настройки сначала выполни детерминированную проверку и
инициализацию через [roblox-init](../roblox-init/SKILL.md). Она сохраняет
существующие документы и добавляет только недостающее. Затем запиши в
профиль наблюдаемые примеры, источник исходников и незаданные решения;
не выдумывай утверждённую палитру. При запросе только объяснения опиши
процесс без изменения файлов.

Для повторяемого сложного элемента используй
[карточку компонента](../../templates/component-pattern.md).
Не создавай пустые карточки для каждого объекта сцены.

Покажи разработчику, где лежат профиль и общие правила и какой skill
применяется к его задаче. Установка этого пакета не подтверждает наличие
Studio MCP, настроенной синхронизации или успешного запуска игры;
проверь нужное подключение перед соответствующей работой.
