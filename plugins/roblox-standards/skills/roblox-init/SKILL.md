# Проверка и инициализация общих файлов

Найди корень целевого проекта по текущему рабочему каталогу и инструкциям
пользователя. Папка установленного плагина не является проектом игры.
Уточнение нужно только если целевой проект невозможно однозначно определить.

Запусти [init_project.py](../../scripts/init_project.py) установленного пакета:

```sh
python3 /путь/к/установленному/плагину/scripts/init_project.py --project /путь/к/проекту --json
```

Вызови скрипт по фактическому пути относительно этого SKILL.md;
не используй буквальные пути из примера. Для аргументов с пробелами
используй корректное quoting или передачу структурированных аргументов.

Скрипт создаёт недостающий профиль, индекс компонентов и конфигурацию;
в AGENTS и README дописывает только отсутствующую маршрутизацию.
Повторный запуск сохраняет существующее содержимое. Для запроса только
проверки или режима Plan добавь `--check`: он ничего не записывает,
а код возврата 1 означает наличие недостающих файлов.

Если у проекта собственный путь профиля вне стандартных кандидатов,
укажи `--design-profile` при первой настройке. Существующая конфигурация
имеет приоритет; не меняй её для обхода конфликта. При ошибке пути,
конфигурации или доступа сообщи точную причину и сохрани файлы.

Покажи созданные и сохранённые документы. Для наполнения профиля на основе
игры используй [roblox-setup](../roblox-setup/SKILL.md).
Автоматическая проверка SessionStart описана в
[документации инициализации](../../docs/initialization.md).
