# Проверка Roblox

Прочитай [руководство проверки](../../docs/testing.md).
Найди ожидаемое поведение и целевые устройства в задаче и документации
текущего проекта. Выбери проверки, которые подтверждают именно это изменение.

Установи текущие place и DataModel, доступ к файлам и подключённой Studio.
Отдели постоянный источник от тестовой симуляции по
[правилам источников](../../docs/source-of-truth.md).
Не выполняй операции с другой открытой игрой по случайному выбору.

Используй соответствующий уровень наблюдения: реальный ввод для UI,
проход для геометрии, движение для VFX, сервер и несколько клиентов
для сетевого поведения, повторный вход для постоянного сохранения.
Прямой вызов функции и чтение свойства проверяют только свой уровень.

При ошибке выясни причину перед зависимыми шагами. Посмотри Output
и различай ошибки продукта и инструмента. Дополнительные проверки
нужны при новом изменении, сбое или нерешённом вопросе.

Если Studio недоступна, выполни применимые проверки файлов и перечисли
оставшиеся живые сценарии. Отчитайся об ожидаемом и наблюдаемом результате,
выполненных проверках и существенных ограничениях.
